怎么看：
· Zard UI（左）—— shadcn 风格：细边框、克制的 8px 圆角、方圆角头像、subtle 阴影、hover 灰底高亮。偏「冷静、专业、信息密度高」，适合数据多的中后台。
· Taiga UI（右）—— 轻盈风格：大圆角、pill 胶囊按钮、行卡片化（行间留白 + hover 上浮阴影）、弹性动画。偏「现代、活泼、呼吸感强」。

注意：这是用纯 HTML/CSS 高保真还原两个库的视觉语言，方便你快速对比风格；真实接入时是 Angular 组件。两者都能对齐你的设计 tokens（主色、圆角、字体）。
