# 成员管理 (member-manage)

## 业务背景
公司管理员管理本公司下所有部门和成员，包括组织架构维护和人员增删改查。

## 页面结构
左侧：部门树（可增删改，支持右键操作）
右侧：选中部门的成员列表（支持筛选、排序、右键操作）

## 关联接口
| 功能 | 接口 | 备注 |
|---|---|---|
| 加载部门树 | GET /organize/load | 需要 companyId |
| 加载成员列表 | GET /organize/member/list | 需要 companyId + deptId |
| 创建部门 | POST /organize/create | |
| 修改部门 | POST /organize/update | |
| 删除部门 | DELETE /organize/delete | 有子部门时不可删 |
| 设置主管 | POST /organize/dept/leader | |

## 业务规则
- 删除部门前必须先删除所有子部门，否则弹提示"请删除所有子部门再进行删除部门操作"
- 删除部门前必须移除部门下所有成员
- 根部门不能删除
- 成员状态筛选：全部、正常、已暂停、未加入、主动退出
- 人员筛选：展示全部人员、仅展示部门直属人员
- 右键成员行：编辑人员信息、设置为主管、直接删除、资源转移并删除
- 更多菜单：批量导入/导出、变更部门、编辑列表、操作离职
- 编辑列表可选列：姓名(不可取消)、人员状态、部门、岗位、登录手机号、登录邮箱、工号、性别、工作邮箱、地区、城市、直属上级、人员类型、入职时间
