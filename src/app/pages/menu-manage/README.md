# 菜单管理 (menu-manage)

## 业务背景
root 管理员管理系统全局菜单树，支持新建、编辑、删除、拖拽排序。

## 页面结构
单表格页面，展示菜单树形列表，支持展开/折叠、勾选、拖拽。

## 关联接口
| 功能 | 接口 | 备注 |
|---|---|---|
| 加载菜单树 | GET /menu/load | root 查全量，admin 查已分配 |
| 菜单详情 | GET /menu/detail | |
| 创建菜单 | POST /menu/create | |
| 更新菜单 | POST /menu/update | |
| 批量删除 | POST /menu/remove | 参数 { ids: string[] } |
| 拖拽排序 | POST /menu/drag | |

## 业务规则
- 勾选父节点：子节点自动全选，checkbox 禁用不可取消
- 取消父节点：子节点解锁恢复可操作
- 全选按钮勾选/取消所有菜单
- 删除前弹确认框，提示"当前菜单下的子菜单也会被一并删除"
- 拖拽支持调整顺序和父子层级
- 点击行打开详情抽屉（编辑模式）
