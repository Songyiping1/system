# 登录页 (login)

## 业务背景
系统登录入口，支持密码登录和验证码登录两种方式。

## 关联接口
| 功能 | 接口 | 备注 |
|---|---|---|
| 密码登录 | POST /User/login | 响应不走 items 包装，字段直接平铺 |

## 业务规则
- 登录成功后根据 orgRole 判断角色，跳转到对应首页
- cookieId 存入 localStorage，后续请求自动带上
- 401 时自动清除 cookieId 并跳回登录页
